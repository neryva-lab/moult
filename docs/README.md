# Moult — Documentation

The public documentation is intentionally focused on the library's behavior,
boundaries, guarantees, and distribution:

- **[`notes/`](./notes/README.md)** — the design: thesis, boundaries,
  lifecycle semantics, positioning, validation, and distribution.
- **[`guarantees.md`](./guarantees.md)** — the named lifecycle guarantees used
  by the API, tests, and issue reports.
- **[`api/`](./api/)** — generated TypeDoc API reference output. It is rebuilt
  by CI for version tags and is not hand-maintained source documentation.

Start with [`notes/01-thesis-and-boundaries.md`](./notes/01-thesis-and-boundaries.md)
and then read [`guarantees.md`](./guarantees.md).
